# Keyboard Shortcuts

Press **?** in the app for its help panel. Shortcuts generally yield to focused text/select/input controls and are restricted while exports are locked.

| Shortcut | Action |
| --- | --- |
| Space | Play/pause visual rendering |
| `[` or Left Arrow | Previous effect |
| `]` or Right Arrow | Next effect |
| `1` / `2` / `3` / `4` / `5` | Effect / FX / Overlays / Audio / Output |
| `N` | Randomize the current effect |
| `B` | Shuffle the open FX, Overlay, or Audio scope; otherwise shuffle FX and overlays |
| `X` | Reset looks: FX, overlays, current effect links, and Club global style |
| `V` | Toggle global beat reactions |
| `S` | Toggle favorite for the effect |
| `P` | Download PNG snapshot |
| `R` | Start/stop the Record workflow |
| `F` | Fullscreen |
| `H` | Hide/show the UI |
| `T` | Show/hide Timeline |
| `G` | Open Gallery |
| `M` | Toggle Studio Music playback |
| `?` | Show help |
| Escape | Close modal dialogs; restore hidden UI |
| Ctrl/Cmd+Z | Undo a supported creative edit |
| Ctrl/Cmd+Y or Ctrl/Cmd+Shift+Z | Redo |
| Double-click slider | Restore that slider's default |

The app's letter handlers use their unshifted lowercase keys; use Shift only where specified. R follows Record Mode and is not a shortcut for the dedicated Render MP4 button. M controls Studio Music, not the uploaded-file playhead.

Text editing retains native undo behavior. The timeline, setup loading, and export locks have their own history/interaction constraints; see [Setups and Undo](Setups-and-Undo.md).
